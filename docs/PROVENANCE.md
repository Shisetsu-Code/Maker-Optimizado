# Provenance and visual continuity

Reference: https://github.com/Shisetsu-Code/Maker at commit 9bc456f6ed1b4344a0cf4fb2e84ca4791061ba10. The previous migrated version in this repository is preserved at 8a8b09cfdda55d8233b2d61c4d878bb112f4f591.

The reference was originally a HAR-derived demonstration. This implementation replaces captured bundles, identifiers, external hosts, catalogs and third-party artwork with newly authored source, neutral labels, declarative presets, and CSS illustrations. Color palettes and general layout families are retained as design inspiration, with a dark/amber editor chrome. This is not an assertion of exact visual equivalence or ownership of the reference material. No unverified third-party logo, font, image or captured code is shipped in this clean tree. Users can import artwork they are authorized to use.

The old Git history has not been rewritten. Preserve relevant ownership, license and attribution records for any future reuse of assets. This document is an audit record, not a UI dependency.
