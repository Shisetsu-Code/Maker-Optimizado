# Provenance and visual continuity

Reference: https://github.com/Shisetsu-Code/Maker at commit 9bc456f6ed1b4344a0cf4fb2e84ca4791061ba10. The previous migrated version in this repository is preserved at 8a8b09cfdda55d8233b2d61c4d878bb112f4f591.

The owner confirmed that the graphic resources, including cinematic compositions, were created for the project with GPT and are authorized for reuse. The clean implementation restores the existing graphical bytes rather than replacing them by generic illustrations. Original raster images are preserved by content address, deduplicated without resizing, while vectors and unrecognized files are preserved outside the public serving directory. The generated asset-provenance.json retains the original paths, hashes, sizes, and serving status. This records the owner's authorization, not independent verification of rights in any third-party marks that may appear in images.

The reference software was originally a HAR-derived demonstration. The new implementation does not import captured bundles, identifiers, external hosts, executable code or original catalog protocols. It uses newly authored Rust and browser glue, neutral template IDs and local graphical resources. The Git history has not been rewritten. No visual pixel equivalence is claimed; original resources are reusable in the new editor.
